ABOUT

About ReturnAI

An AI-powered e-commerce return prediction project built using machine learning.

Developed by Shivam Shrivastav

ReturnAI is an end-to-end machine learning project designed to estimate whether an e-commerce order is likely to be returned.

The system takes customer and order information, processes the data using a trained preprocessing pipeline, and uses a trained machine learning model to generate the return prediction.
